# Dr. Weslley Oliveira — Landing Page de Advocacia Digital

Landing page profissional para o escritório de advocacia especializado em **Direito Digital, LGPD, vazamento de dados e indenizações**.

## Sobre o projeto

Site de portfólio institucional com design moderno e responsivo, desenvolvido para apresentar os serviços jurídicos na área de proteção de dados pessoais e conformidade com a LGPD.

### Funcionalidades

- **Hero Carrossel** com 3 slides temáticos e navegação por setas/dots
- **Seção de áreas de atuação** com cards interativos
- **FAQ Accordion** em 4 páginas especializadas:
  - Vazamento de Dados Pessoais
  - Segurança e Privacidade Digital
  - Indenizações e Danos Morais
  - Conformidade com a LGPD
- **Banner de cookies** com consentimento LGPD
- **Carregamento sob demanda** do Google Analytics (após aceite)
- **Animações em scroll** (Intersection Observer)
- **Galeria de fotos** com placeholder profissional
- **Schema.org / JSON-LD** para SEO estruturado
- **Open Graph** para compartilhamento em redes sociais
- **Design responsivo** (desktop, tablet e mobile)

### Tecnologias

- HTML5 semântico
- CSS3 (flexbox, grid, animações, media queries)
- JavaScript vanilla (ES6+)
- Google Fonts (Lato, Montserrat, Playfair Display, Manrope, Open Sans)
- Firebase Hosting (deploy)

### Páginas

| Página | Descrição |
|--------|-----------|
| `index.html` | Página principal com carrossel, áreas de atuação e CTA |
| `vazamento-dados.html` | FAQ sobre vazamento de dados pessoais |
| `seguranca-privacidade.html` | FAQ sobre segurança e privacidade digital |
| `indenizacoes-danos.html` | FAQ sobre indenizações e danos morais |
| `conformidade-lgpd.html` | FAQ sobre adequação à LGPD |

### Deploy

O deploy é feito via Firebase Hosting:

```bash
firebase deploy
```
